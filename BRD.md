# BRD — MyLesson.ai

## 1. Product Overview
**MyLesson.ai** is a curriculum-agnostic AI teaching assistant that helps teachers convert their own syllabus, curriculum, or source material into lesson plans, learning materials, explanations, quizzes, and classroom activities.

**Core principle:** AI drafts; the teacher reviews and approves.

## 2. Problem
Teachers spend substantial time preparing lessons, materials, activities, and assessments. Generic AI tools can generate content but often lack:
- Persistent teaching context
- Grounding in prescribed material
- Structured, reusable artifacts
- Explicit connection between learning objectives and assessments

## 3. Target Users
- School teachers
- College/university educators
- Tutors and trainers

## 4. Objectives
- Reduce preparation effort
- Keep generated content aligned with the teacher's curriculum
- Make learning objectives central to planning and assessment
- Support differentiated teaching
- Keep the teacher in control of final content

## 5. Core Features

| Feature | Description |
|---|---|
| Curriculum Lens | Understand uploaded syllabus/source material and extract teaching context |
| Lesson Studio | Generate structured, timed lesson plans with objectives and checks for understanding |
| Concept Simplification | Explain concepts at an appropriate level using examples and analogies |
| Learning Materials | Generate handouts, revision summaries, worksheets and board/slide outlines |
| Classroom Activities | Generate activities based on topic, time, class size and resources |
| Quizzes & Assessments | Generate questions with difficulty control, answer keys and objective coverage |
| Adapt | Adapt existing content for learner levels or classroom constraints |
| Review & Approve | Edit, regenerate sections and explicitly approve before export |
| Artifact Library | Store, version and reuse generated teaching artifacts |

## 6. Key Differentiators
1. **Curriculum-agnostic by construction** — curriculum details are data, not hardcoded board-specific logic.
2. **Grounded generation** — uploaded source material can be retrieved and cited.
3. **Objective-aware assessment** — learning objectives connect lesson content to quiz questions.
4. **Human-in-the-loop** — no artifact becomes approved automatically.
5. **One Teaching Context, many outputs** — the same context powers all generation features.

## 7. Scope

### MVP
- Curriculum/source upload
- Teaching Context extraction
- Lesson plan generation
- Concept simplification
- Activities
- Learning materials
- Quiz generation
- Basic objective alignment
- Review/edit/regenerate
- Approval and export
- Basic artifact library

### Out of Scope
- Student accounts
- Student data collection
- Auto-grading
- Attendance/timetabling
- Parent communication
- Live class/video delivery
- LMS integrations
- Advanced student analytics

## 8. Success Metrics
- Time required to create a lesson plan
- Percentage of generated artifacts aligned with selected objectives
- Percentage of quiz questions mapped to taught objectives
- Teacher approval/edit rate
- Generation success rate
